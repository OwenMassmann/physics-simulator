# Physics Simulator

A Python-based projectile motion simulator built while learning Python and studying introductory physics.

## What It Does

- Calculates projectile flight time
- Calculates maximum height
- Calculates horizontal range
- Compares multiple launch angles
- Displays projectile trajectories using a graph

## Technologies

- Python
- Matplotlib
- Basic physics and mathematical modeling

## Example

The program compares launch angles from 15° to 75° and determines which angle produces the greatest horizontal range.

## What I Learned

This project helped me practice Python programming while applying concepts from introductory physics, including projectile motion, trigonometry, and mathematical modeling.
